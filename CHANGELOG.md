All notable changes to Linger are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/). Versions are release times,
`YYYYMMDD-HHMM` in the maintainer's local time: a version says when a release was made, not
whether it is compatible with the one before. Each section says what changed.

## [20261101-2151] - 2026-11-01

### Added

- Linger keeps your Mac active while you're away.
- Linger steps aside while macOS switches between light and dark appearance, so the change is
  not held back.
- Pause Linger for a while from the menu bar, and resume it at any time.
- Linger stops when the screen is locked and carries on when you unlock it.
- Linger can start when you log in.
- A Settings window to adjust Linger, with the version shown under About.
- Install with Homebrew: `brew install --cask michaelrigart/tap/linger`.
- Releases are signed, so the Accessibility permission you give Linger survives updates.
